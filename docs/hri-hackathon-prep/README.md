# HRI Hackathon Thailand 2026: Readiness Search

Readiness Search คือระบบค้นหางานวิจัย (เปเปอร์), GitHub repo (คลังเก็บโค้ดบนเว็บ GitHub) และข้อมูลหุ่นยนต์จากฐานข้อมูลรวม 6,749 รายการในหน้าเดียว ระบบใช้ semantic search (การค้นหาด้วยความหมาย ไม่ใช่แค่คำตรงตัว) เพื่อหาสิ่งที่เกี่ยวข้องกันมาให้พร้อมกัน

นักวิจัยสามารถเลือก 2-3 รายการมาวางเทียบกันในตาราง Readiness (Readiness table หรือตารางเทียบความพร้อมใช้งาน) ตารางนี้จะแสดงเฉพาะข้อมูลที่ยืนยันจากต้นทางได้จริงเท่านั้น หากช่องไหนไม่มีข้อมูล ระบบจะแสดงคำว่า `unknown` (ไม่ระบุเพราะไม่มีข้อมูลยืนยัน) และจะไม่เดาเอาเองว่าโค้ดหรือหุ่นยนต์ใช้งานร่วมกันได้

เบื้องหลังระบบใช้เวกเตอร์ (vector หรือชุดตัวเลขแทนความหมายของข้อความ) ที่คำนวณไว้ล่วงหน้าด้วยโมเดล Qwen3-Embedding 0.6B (โมเดล AI สำหรับแปลงข้อความเป็นชุดตัวเลข) หากรอยต่อสำหรับแปลงคำค้นสดอย่าง query API (ระบบแปลงคำค้นเป็นเวกเตอร์ในจังหวะที่กดค้นหา) ใช้งานไม่ได้ ระบบจะสลับไปค้นด้วย keyword (คำค้นตรงตัว) ก่อน แล้วดึงรายการที่มีเวกเตอร์ใกล้เคียงมาขยายผลลัพธ์ พร้อมขึ้นแบนเนอร์แจ้งสถานะบนหน้าจอ

เมื่อเทียบข้อมูลเสร็จ ผู้ใช้สามารถบันทึกเหตุผลที่เลือกหรือตัดแต่ละรายการออก พร้อมระบุ next action (สิ่งที่ต้องทำต่อ) 1 บรรทัดเพื่อกลับมาทำต่อทีหลัง และสั่ง export (ส่งออกข้อมูลเป็นไฟล์) ในรูปแบบ `decision-brief.json` หรือ `.md` ได้

รายละเอียดสเปกและเกณฑ์ผ่านทั้งหมดอยู่ใน [HERO-FEATURE.md](HERO-FEATURE.md)
